# 札记 / Glean

根据提供的界面参考及安静阅读要求开发的 Chrome / Edge 阅读插件，当前版本为 **0.3.7 本机飞书同步版**。

## 安装

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目中的 `extension` 文件夹（其中包含 manifest.json）。
4. 将「札记 Glean」固定到浏览器工具栏，刷新已经打开的文章网页。
5. 选中文字、松开鼠标即自动保存并展开记录框；点击插件图标直接打开本篇记录。侧栏右上角「···」可进入收获库或设置。

压缩包版本先解压，再选择其中的 extension 文件夹。后续升级保持此文件夹位置不变，替换文件并在扩展管理页点击刷新。不要为了更新而卸载，卸载会删除本地记录。

## 已可使用

- 记录框下方直接多选标签：内容选题、产品选题、写作方法、非生业务、工具方法；自动保存，再次点击取消。新记录默认处理状态为“未处理”，完成转化后可改为“已转化”或“已归档”。收获库支持标签筛选及编辑，导出保留全部标签；旧分类兼容为对应标签。

- 网页选中文字：自动保存并在侧栏展开想法框，不抢输入焦点；同一位置重复划线复用记录。稍后标记可在记录框下方一键选择，分类在详情里修改。
- 独立记录灵感；所有标记操作无需必填想法或分类。
- 右侧本篇记录默认 300px，拖动左边缘可在 240–480px 间调整，自动记住宽度。只展示当前文章的记录，按能定位到的原文顺序排列。
- 点击划线展开想法，输入自动保存；关闭侧栏前保存未完成的输入。保存失败保留草稿并提供重试。出处、时间、分类与上下文收在「详情」里。
- 底部「记想法」支持不关联划线的独立记录；收获库及设置收在小菜单中。
- 收获库搜索、类型 / 来源 / 时间筛选、收藏、移除稍后标记、删除与短时间撤销。
- 搜索支持从中文问句提取关键词，**当前不是 AI 语义搜索**。
- 内容及产品灵感列表、Markdown 汇总导出、JSON 备份与导入恢复。
- 持久保存飞书目标文档链接、每日 08:10 / 每周五 14:05 提醒偏好（北京时间），以及悬浮入口开关。
- 窄窗口下收获库可在列表与详情间切换。

## 本机飞书同步

已在当前电脑配置同步助手，使用「札记Glean-新应用」的孙欣用户授权。写入「札记Glean / 阅读与灵感库 / 阅读记录」。先本地保存，约数秒后排队上传；网络或授权失败后每分钟重试。删除与撤销更新云端「已删除」标记，不物理删除云端行。

当前安装位置仍为 `dist/glean-0.2.1/extension`（目录名不等于实际版本），内含这台电脑的本地配对配置。更新时应保留该目录及 `local-sync-config.js`。通用安装包不包含配对密钥，不能直接替换此文件后期待自动连接。

助手仅监听 `127.0.0.1:4174`，校验配对信息，CLI 保管飞书授权。Windows 登录后隐藏启动；首次收到每个浏览器的数据前，在 `.local/backups` 保存完整备份。`.local` 不应公开或打包分享。同步队列保存在 `.local/outbox.json`，助手重启后继续处理。

在插件「设置 → 连接与同步」查看状态或立即同步。请在札记中编辑记录，飞书直接编辑的内容暂不回传；以后再次修改对应本地记录时，会更新飞书这一行。

## 当前边界

- **已配置当前电脑到飞书的单向自动保存。公司电脑、跨电脑读取、飞书编辑回传、日程创建、手机通知和 OB 自动采集尚未接入。** 日程开关只保存偏好，不代表已开始提醒。
- 支持普通可选中文本网页及匹配域名的 iframe 阅读区域。纯 canvas、无文本层及受限制的内容仍不能通用划线；得到会员正文尚未在登录状态下实测。
- 在网址以 .pdf 结尾的 PDF 页面点击札记，会另开札记 PDF 阅读页。点击“打开此 PDF”按网站授权读取，或选择本地 PDF。支持翻页、选择文字、记录及标签，记录标题包含页码；扫描页只有具备文字层才能划线，不包含 OCR。PDF.js 6.3.289 及解码资源随扩展打包，不依赖境外 CDN。
- 本地 PDF 以文件内容摘要区分同名文件。文件本身不上传飞书；原文与想法按原规则同步。当前本地 PDF 未缓存，重新阅读需要再次选择该文件，跨设备也需各自持有文件。
- 本地 HTML 页面需要在扩展详情页允许访问文件网址。浏览器内部页面和扩展商店无法注入。
- 定位原文依赖原文仍存在。动态页面变化或重复引文无法唯一定位时会提示，可查看保存的上下文。
- 同步范围是用户主动记录的原文摘录、想法、出处、时间、标签及上下文，不采集整篇正文。不加载外部字体或脚本。
- 页面正文在宽屏打开侧栏时让出空间；特殊网站布局仍需逐站验证。

## 预览与开发

无需构建，无生产依赖。Node.js 22+：

```powershell
npm run dev
```

打开 `http://127.0.0.1:4173/app.html?demo=1` 查看有示例数据的设计预览；去掉 `?demo=1` 是空白真实本地模式。示例数据与真实记录分开存储。

打开 `http://127.0.0.1:4173/reader.html?demo=1&panel=1` 查看左侧文章、右侧安静侧栏的新版预览。`reader.html` 是可体验划线的练习文章。网页预览的数据使用网站 localStorage；安装后的插件使用 chrome.storage.local，两者不会自动合并。

```powershell
npm test
npm run check
npm run package
```

## 后续接入

飞书适配应在独立服务处理授权与凭据，提供文档归档、增量同步和日程更新；客户端不保存应用密钥。日程需要幂等创建，并在北京时间每日 08:10、每周五 14:05 通知，链接到已生成的汇总文档。复用已有 OB 定时任务，避免重复采集。日程目的是查看文档并明确下一步行动，不自动派发创作任务。

插件基于 [Chrome Manifest V3](https://developer.chrome.com/docs/extensions/reference/manifest) 和 [Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)，本地记录逐条存储，后台串行处理同一记录的修改，避免跨页面整体覆盖。
